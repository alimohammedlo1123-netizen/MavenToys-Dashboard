# 🧸 Maven Toys Sales Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing **Maven Toys sales data** to discover business insights and understand sales performance.

The project includes data analysis, visualization, and an interactive dashboard that presents the most important sales metrics in a simple and clear way.

## 🚀 Live Demo

👉 **[Try the Movie Recommendation System](https://maventoys-dashboard-nshcamtmwqinfbfddlbgvp.streamlit.app/)**

## 🎯 Project Objectives

* Analyze sales performance.
* Identify sales trends and patterns.
* Understand product and store performance.
* Compare sales across different periods.
* Extract meaningful business insights from the data.
* Present the results through an interactive dashboard.

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Streamlit** – Interactive dashboard
* **Jupyter Notebook** – Data analysis
* **Git & GitHub** – Version control

## 🚀 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/alimohammedlo1123-netizen/MavenToys-Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd MavenToys-Dashboard
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
streamlit run maven.py
```
